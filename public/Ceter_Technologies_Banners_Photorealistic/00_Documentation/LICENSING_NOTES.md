# Font and Image Licensing Notes

## Fonts

No text is baked into the delivered banner images. For website-rendered copy, use **Inter** (SIL Open Font License 1.1) with Arial or a system sans-serif fallback. Font files are not included in this package.

## Images

The photographic source images were supplied in the current ChatGPT conversation and were treated as user-provided production assets. No external stock-library images were downloaded or added. Ceter Technologies should retain or confirm the applicable commercial-use rights for these source images before public deployment.

## Editable files

The SVG files are layered equivalents. They retain separate photographic, gradient-overlay and brand-accent groups and link to the optimized source assets supplied in this package.
