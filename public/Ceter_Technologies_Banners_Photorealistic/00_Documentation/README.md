# Ceter Technologies Photorealistic Banner Package

This package contains nine banner concepts with separate desktop and mobile compositions. The imagery remains photographic, website headlines and buttons are not baked into the exports, and every JPG/WebP export is below 1 MB.

## Deliverables

- 9 desktop JPG files
- 9 desktop WebP files
- 9 mobile JPG files
- 9 mobile WebP files
- 18 editable SVG source files with named image, overlay and accent layers
- 5 optimized photographic source assets
- Desktop and mobile preview sheets
- File manifest, copy guide and licensing notes

## Colour palette

- Navy: #0B1E39
- Teal: #14B8A6
- White: #FFFFFF
- Light background: #F7F8FA
- Slate: #334155 and #0F172A
- Amber: #D97706

## Editing the source files

Open the SVG files in Adobe Illustrator, Affinity Designer, Figma, Inkscape or a modern browser. The photographic layer, text-safe gradient and brand accents remain separate named groups. The SVG files reference the optimized assets in `00_Source_Assets`; preserve the folder structure when editing.

No headlines, supporting copy, buttons or website controls are embedded in the image exports.
